# Imágenes de Sofia Meag

## Instrucción importante:

Debes agregar la imagen de la historia de Instagram (la que muestra "Clases de Yoga By Sofia Meag") en esta carpeta con el nombre `sofia-hero.jpg`.

Esta imagen se utilizará en:
- La sección "Sobre Mí" como imagen principal
- En la galería de fotos

## Formato recomendado:
- **Nombre:** `sofia-hero.jpg`
- **Tipo:** JPG o PNG
- **Dimensiones recomendadas:** Al menos 800x1000px para buena calidad

## Cómo agregar la imagen:

1. Guarda la imagen de la historia de Instagram
2. Renómbrala a `sofia-hero.jpg`
3. Cópiala en esta carpeta (`landing-page/images/`)

Una vez agregada, la imagen se mostrará automáticamente en el sitio web.
